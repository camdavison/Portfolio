# Cam Davison Portfolio

Restored static portfolio site, exported from Webflow and prepared for independent hosting.

## Local preview

Run a static server from this directory, for example:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

This repository is configured as a static Vercel project. No build command is required; the repository root is the published directory.
